Estrutura do Tech Code

Navegação principal e módulos do sistema — confirme se faz sentido antes de detalharmos cada tela.

📊 Dashboard

Métricas em tempo real: OS abertas, receita do mês, lucro, comissões pendentes. Acesso: Admin.

👤 Clientes

Lista de clientes. Perfil com histórico completo de OS, contatos e veículos. Todos os perfis.

🔧 Ordens de Serviço

Lista de OS com filtros por status. Criar nova OS com fotos, comentário, defeito, peças usadas e técnico responsável.

🖥️ Centrais (Base de Conhecimento)

Lista de modelos de ECU. Ao clicar: todos os defeitos já resolvidos naquele modelo + cliente vinculado.

💰 Financeiro

Receita, custo de peças, lucro líquido, relatórios mensais e comissões por técnico. Acesso: Admin.

👥 Equipe

Cadastro e gestão de usuários (admin, atendente, técnico). Define comissão % por técnico. Acesso: Admin.

Fluxo principal de uma OS
Cliente chega → Atendente abre OS → Técnico registra defeito + fotos + peças → Admin aprova e fecha OS → PDF gerado
