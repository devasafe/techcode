Onde o Tech Code vai rodar?

Isso define a arquitetura inteira — escolha o cenário que mais se encaixa na sua rotina no laboratório.

A

Aplicação Web (navegador)

Abre no Chrome/Edge de qualquer PC ou celular na rede. Hospedado localmente ou na nuvem. Sem instalação.

B

Aplicativo Desktop (Windows)

Instalado no PC do laboratório. Funciona offline, sem dependência de internet ou servidor.

C

Web + Mobile (PWA)

Roda no navegador do PC e pode ser instalado no celular como app. Boa cobertura, um código só.
